# aws-restart-portfolio
Projetos Laboratórios e automações que desenvolvi durante o programa AWS re/Start
## 🛠️ Tecnologias e Ferramentas
* **Nuvem:** AWS (EC2, S3, VPC, IAM, CloudFormation)
* **Sistemas Operacionais:** Linux (Scripts em Bash)
* **Programação:** Python (Biblioteca Boto3)

## 📂 Estrutura do Repositório
* `/linux-automation`: Scripts criados para automatizar tarefas e servidores no Linux.
* `/python-projects`: Códigos em Python integrados com serviços de nuvem.
* `/aws-infrastructure`: Arquiteturas de rede e modelos de infraestrutura como código.
